UBUNTU PACKAGES IN THE BASE IMAGE

The Station eth-rpc image is built on Parity's image parity/eth-rpc:v1.25.0, which is
built on Ubuntu 22.04 (jammy). The packages below are the Ubuntu packages in
it, unmodified, each under its own license. Each Ubuntu package's own
license and copyright notice is in the image at
/usr/share/doc/<package>/copyright.

The list is read from the dpkg database of every layer of the image, so it
includes packages whose programs were deleted from the final filesystem by a
later layer but are still stored in the earlier layers of the image. Those are
marked 'not in final dpkg database'.

Source for each package, at the version shown, is published by Ubuntu:
  - Launchpad: https://launchpad.net/ubuntu/+source/<source package>/<version>
    (the link given for each package, with the source files under 'Source files')
  - Archive:   https://archive.ubuntu.com/ubuntu/pool/ and
    https://old-releases.ubuntu.com/ubuntu/pool/
  - Or run, on an Ubuntu 22.04 system with deb-src enabled:
    apt-get source <source package>=<version>
